# 网盘系统部署说明

## 目录结构

```
/var/www/html/pan/
├── index.html          # 前端界面
├── upload.php          # 文件上传处理
├── download.php        # 文件下载处理
├── files.php           # 获取文件列表
├── .htaccess           # 访问权限配置
└── uploads/            # 文件存储目录
    └── .htaccess       # 上传目录权限配置
```

## 部署步骤

1. 创建目录结构
2. 上传所有文件到对应位置
3. 配置Nginx虚拟主机
4. 配置域名解析
5. 设置文件权限

## 功能说明

- 文件上传：支持拖拽上传和点击上传
- 文件列表：显示所有上传的文件
- 文件下载：支持直接下载文件
- 文件删除：支持删除不需要的文件

## 注意事项

- 确保uploads目录有写入权限
- 定期清理上传的文件，避免服务器空间不足
- 建议设置文件大小限制，防止大文件占用过多空间
